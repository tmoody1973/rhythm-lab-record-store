# Website Implementation Plan (milestone 2, plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static site that loads `catalog.json` and lets anyone browse Tarik's 1,215 records as a cover grid, open any record in a pop-up with Bandcamp's player, and save their own hearts and crates (shareable by link), alongside Tarik's own crates.

**Architecture:** Vite + React + TypeScript single-page app. Pure catalog logic (ids, genres, filter/sort/A–Z/pagination, share-link codec, crate merge) lives in `src/catalog/` and `src/crates/` and is unit-tested without a DOM. UI components in `src/ui/` read one URL-backed state model. The site fetches `/catalog.json` at runtime (generated by plan 1, git-ignored); tests use `fixtures/catalog-sample.json`. No server, no accounts.

**Tech Stack:** vite 8.3.4, @vitejs/plugin-react 6.1.2, react/react-dom 19.3.1, tailwindcss + @tailwindcss/vite 4.3.3, zod (installed), vitest (installed) + jsdom 30.1.3 + @testing-library/react 16.3.3, user-event 14.6.8, jest-dom 7.0.1, @playwright/test 1.64.1, @fontsource/libre-caslon-text and @fontsource/inter-tight 5.3.0 (self-hosted fonts).

**Spec:** `docs/superpowers/specs/2026-10-19-record-store-v1-design.md` (sections 3–5, Constraints, Anti-goals). Behaviour rules it inherits: `docs/BUILD-PLAN.md` sections "Organize by genre and alphabetical order", "Make 1,296 items easy to browse", "Preserve your place when opening a record", "Core interaction: an engaging album modal". Visual source of truth: `docs/design/rhythm-lab-record-shop.png` (header, chips, palette) and `docs/design/rhythm-lab-album-modal.png` (pop-up).

## Global Constraints

- **Look:** recreate the mockups. Tokens (sampled from the PNGs) go in `src/styles.css` `@theme`: `--color-wall: #ede4d5` (page), `--color-paper: #efe9dd` (header), `--color-card: #f3efe8` (pop-up), `--color-chip: #f4e9d7`, `--color-line: #e7dcce`, `--color-forest: #364c43` (primary buttons, active chips), `--color-forest-ink: #1a2d25` (spaced-caps labels), `--color-ink: #131718`, `--color-ink-soft: #444342`, `--color-walnut: #693c1e`. Fonts: Libre Caslon Text (headlines, titles) and Inter Tight (UI), self-hosted via @fontsource; use Tailwind v4's stable `--font-*` theme namespace. Rounded pill chips, spaced small caps for labels, large serif titles.
- **Third-party content:** only Bandcamp's player iframe (`https://bandcamp.com/EmbeddedPlayer/...`), one at a time, mounted when the pop-up opens and unmounted on close. Covers are self-hosted `/covers/...`. No analytics, no other external requests.
- **Ids:** catalog ids are `bandcamp:album:<n>` / `bandcamp:track:<n>`. The compact form `a<n>` / `t<n>` is used in URLs and share links. One converter (`src/catalog/ids.ts`) handles both; nothing else formats ids.
- **Embed URL:** `https://bandcamp.com/EmbeddedPlayer/<album|track>=<n>/size=large/bgcol=f3efe8/linkcol=364c43/tracklist=true/transparent=true/` (verify colours render; adjust only `bgcol`/`linkcol`).
- **Behaviour rules from BUILD-PLAN:** filters apply before sort and pagination; genres multi-select OR, different filter types AND; default sort Artist A–Z with title then id as tie-breakers; `Intl.Collator(undefined, { sensitivity: 'base', numeric: true })`; A–Z/`#` jump reaches records beyond the current page and disables empty letters; 48 cards per page; result count announced politely; empty state with a reset action.
- **Accessibility:** native `<dialog>` with `showModal()`, named, visible close button, Escape closes, focus returns to the originating card; real buttons/links; visible focus; `prefers-reduced-motion` honoured; usable at 390 px wide with no horizontal scroll.
- **Visitor data stays in the visitor's browser** (`localStorage`, wrapped in try/catch, zod-validated). Never sent anywhere.
- **No deploy** in this plan. CI must stay green on every PR (main is protected; work on a branch, merge via PR).
- **Working style (from bookshelf):** after every visual task, take Playwright screenshots at 1440×900 and 390×844 against the dev server and compare them with the mockups before reporting.

## Review Focus

1. `localStorage` unavailable (private mode), full, or holding corrupt/old-schema data → the site works, a small "saving is off in this browser" or "saved picks were reset" notice appears, nothing crashes. (Task 6 test)
2. A malformed or hostile share link (bad base64, >200 ids, unknown ids, `<script>` in the name, 10 KB name) → rejected or cleaned with a notice; the name renders as text; unknown ids are dropped. (Task 6 test)
3. `/catalog.json` missing, not JSON, or failing the schema → a friendly error panel with what to do, not a blank page. (Task 3 test)
4. A direct link with `?record=` for an unknown or malformed id → no pop-up, a notice, the collection still loads; a valid direct link's close goes to the collection, not out of the site. (Task 5 test)
5. Records with `cover: null` (1 real one) and with `genre: null` (118) → a typographic placeholder sleeve and the Unclassified genre, never a broken image or a missing card. (Task 4 test)

### Task 2: Catalog logic — ids, genres, filter, sort, A–Z, pages

**Files:** Create `src/catalog/ids.ts`, `src/catalog/genres.ts`, `src/catalog/query.ts`, `tests/web/query.test.ts`.

**Interfaces:**
- Consumes: `PublicAlbum`, `Catalog` from `src/catalog/schema.ts` (plan 1).
- Produces:
  - `ids.ts`: `toCompact(id: string): string | null` (`bandcamp:album:7` → `a7`); `fromCompact(c: string): string | null`; `embedUrl(r: Pick<PublicAlbum, 'kind' | 'bandcampId'>): string` (Global Constraints format).
  - `genres.ts`: `type Genre = { slug: string; label: string }`; `genreOf(raw: string | null): Genre` (`'r&b soul'` → `{ slug: 'soul-rnb', label: 'Soul / R&B' }`, `null` → `{ slug: 'unclassified', label: 'Unclassified' }`, unknown → capitalised label, slugified); `genreChips(albums: PublicAlbum[], minCount = 50): { visible: (Genre & { count: number })[]; more: (Genre & { count: number })[] }` (Unclassified always in `more`). Alias table: jazz→Jazz, electronic→Electronic, r&b soul→Soul / R&B, hip hop rap→Hip-hop, world→Global sounds, experimental→Experimental, funk→Funk, alternative→Alternative. *(Claude's call: `minCount` 50 gives 7 visible genres for today's catalog, close to the mockup's chip count.)*
  - `query.ts`: `type SortKey = 'artist-asc' | 'artist-desc' | 'title-asc' | 'title-desc'`; `type Query = { q: string; genres: string[]; crate: string | null; sort: SortKey; page: number }`; `applyQuery(albums: PublicAlbum[], query: Query, crateMembers: Set<string> | null): PublicAlbum[]` (filter then sort, no paging); `letterOf(s: string): string` (`A`–`Z` after stripping diacritics, else `#`); `letters(sorted: PublicAlbum[], sort: SortKey): Set<string>`; `firstIndexForLetter(sorted, sort, letter): number` (−1 if none); `pageOf(index: number, perPage = 48): number` (1-based); `pageSlice(sorted, page, perPage = 48): PublicAlbum[]`; `pageCount(n, perPage = 48): number`.

- [ ] **Step 1: Failing tests** in `tests/web/query.test.ts` using `fixtures/catalog-sample.json` plus small hand-made records:
  - `toCompact('bandcamp:track:45593149') === 't45593149'`; `fromCompact('a7') === 'bandcamp:album:7'`; `fromCompact('x7') === null`; `fromCompact('a7x') === null`.
  - `embedUrl({ kind: 'track', bandcampId: 45593149 })` starts with `https://bandcamp.com/EmbeddedPlayer/track=45593149/`.
  - `genreOf('r&b soul').label === 'Soul / R&B'`; `genreOf(null).slug === 'unclassified'`; `genreOf('soundtrack').label === 'Soundtrack'`.
  - Sorting: `artist-asc` orders `'Ólafur'` with the Os (diacritics), `'beck'` before `'Björk'` (case-insensitive), `'2Pac'` before `'10cc'` (numeric: `2` < `10`), equal artists fall back to title, equal titles fall back to id; `artist-desc` is the exact reverse.
  - Filtering: `genres: ['jazz', 'soul-rnb']` returns records in either (OR); adding `q: 'chiu'` narrows to matches in artist or title (AND), case- and accent-insensitive; a record never appears twice.
  - `letterOf('Ólafur') === 'O'`, `letterOf('2Pac') === '#'`, `letterOf('!!!') === '#'`.
  - `firstIndexForLetter` on a 120-record sorted list returns an index on page 3 → `pageOf(i) === 3`; a letter with no records returns −1 and is absent from `letters(...)`.
